## Batch limits (checked alongside row 8)

Confirmed on the batch page: a batch holds 100,000 requests or 256 MB, whichever comes first. Most batches finish within 1 hour; batches expire after 24 hours; results are available for 29 days after creation.

## Changes since 2026-10-09

- **Subagent frontmatter:** more fields than the 2026-10-09 sheet listed (`memory`, `background`, `omitClaudeMd`, `isolation`, `color`, `initialPrompt`, `experimental`). `permissionMode` also gains `auto` and `manual`.
- **Nested skills:** `<subdir>/.claude/skills/` is documented as discovered on demand, which the 2026-10-09 sheet did not cover.
- **Structured outputs:** `output_format` is deprecated; use `output_config.format`.
- **Managed Agents vaults:** env-var credentials are placeholders substituted at egress, the agent never sees the value; max 20 credentials per vault; the host must be allowed at both the credential and the environment level.
- **Managed Agents skills:** max 500 skills per session; repo skills are scanned once at session start, so pushed commits need a new session.
- **Headless:** `--permission-prompts none` (v2.1.259+) for unattended runs. Bare mode also skips subagents and plugins; skills in an `--add-dir` directory still load.
- **Subscription token:** `setup-token` tokens cannot establish Remote Control sessions or fetch claude.ai connectors; local MCP servers still work.
- **Unverified:** the "three layers" subagent nesting default was not found on the fetched pages.
